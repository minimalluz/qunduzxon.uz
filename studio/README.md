# Админ панел (Sanity Studio)

Сайт матнларини код ёзмасдан ўзгартириш учун. Манзили: **qunduzxon.uz/admin** (ёки тўғридан-тўғри https://qunduzxon.sanity.studio).

Интерфейс тугмалари русча (Sanity'да ўзбекча интерфейс йўқ), майдонлар номи ўзбекча.

## Админ панелда нима бор

| Бўлим | Нима учун |
| --- | --- |
| **Сайт созламалари** | Telegram username, телефон, email, Instagram/YouTube/TikTok/Facebook ҳаволалари, рақамлар (эфирда неча йил, тадбирлар, обуначилар) |
| **Фуд-блог шарҳлари** | Ресторан шарҳлари: ўзбекча ва русча матн, расмлар, видео, баҳолар, манзил |
| **Отзывлар** | Мижозлар фикри — хизмат саҳифасида (масалан «Тўй ва тантаналар») кўринади |
| **Ҳамкорлар** | Бош саҳифадаги ҳамкорлар: номи, логотипи, сайти |

## Эга учун: қандай ишлатиш

### Янги шарҳ қўшиш

1. Чапда **Фуд-блог шарҳлари** → юқоридаги **+** (ёки «Создать»).
2. **Асосий** бўлими: номи, **Манзил (URL)** ёнидаги **Generate** тугмаси (номдан ўзи ясалади), сана, ошхона тури.
3. **Ўзбекча матн**: қисқа хулоса (1–2 гап), шарҳ матни, шаҳар, манзил.
4. **Русча матн** — ихтиёрий. Русча **номи** ва **қисқа хулосаси** бўлмаса, шарҳ фақат ўзбекча сайтда чиқади.
5. **Расм ва видео**: асосий расм (мажбурий), галерея, видео-обзор (MP4).
6. **Жой ва баҳо**: ўртача чек, иш вақти, харита ҳаволаси, 4 та баҳо (0–10). Умумий балл ўзи ҳисобланади.
7. Пастдаги **Publish / Опубликовать** тугмаси. Сайт 1–3 дақиқада янгиланади.

Сақланган, лекин эълон қилинмаган (Publish босилмаган) ўзгаришлар сайтда кўринмайди — бемалол қоралама қилиб туриш мумкин.

### Бошқа ишлар

- **Расмда юзни марказга олиш:** расмни очиб, ✎ (crop) → доирачани юзга қўйинг. Сайт карточкаларда шу нуқтани марказда кўрсатади.
- **Намуна шарҳ:** «Намуна» белгиси ёқилса, сайтда «намуна» ёзуви чиқади ва Google'га берилмайди.
- **Шарҳни ўчириш:** шарҳни очинг → ⋯ → Delete (Удалить). Вақтинча яшириш учун: ⋯ → Unpublish.
- **Расмни алмаштириш:** расм устида ⋯ → Replace.
- **Хато қилиб қўйсангиз:** ўнг юқорида соат белгиси (History) — олдинги ҳолатга қайтариш мумкин.

## Созлаш (бир марта, техник иш)

Ҳозир сайт маълумотни файллардан олади. Sanity уланганда — админ панелдан. Улашгунча ҳеч нарса ўзгармайди.

1. **Sanity лойиҳаси.** https://www.sanity.io/manage → Google билан кириш → **Create project** → номи `qunduzxon`, dataset `production` (public). **Project ID** ни кўчириб олинг (масалан `ab12cd34`).
2. **Project ID ни ёзиш:** `studio/env.ts` даги `todo-project-id` ўрнига.
3. **Админ панелни жойлаш:**
   ```bash
   cd studio
   npm install
   npx sanity login
   npm run deploy
   ```
   Манзил `https://qunduzxon.sanity.studio` бўлади. Бу ном банд бўлса, `sanity.cli.ts` даги `studioHost` ни ва `site/public/_redirects` даги `/admin` қаторини ўзгартиринг.
4. **Cloudflare Pages → Settings → Environment variables:**
   | Ном | Қиймат |
   | --- | --- |
   | `SANITY_PROJECT_ID` | 1-қадамдаги Project ID |
   | `SANITY_DATASET` | `production` |

   Шундан кейин сайт маълумотни Sanity'дан олади. **Диққат:** файллардаги 3 та намуна шарҳ (`site/src/content/reviews*`) шунда сайтдан йўқолади — шарҳлар энди фақат админ панелдан.
5. **Publish босилганда сайт ўзи янгиланиши учун:**
   - Cloudflare Pages → Settings → Builds → **Deploy hooks** → Add (номи `sanity`, шохча — production шохчаси) → URL ни кўчиринг.
   - sanity.io/manage → лойиҳа → **API → Webhooks → Create webhook**: URL — шу deploy hook, Dataset — `production`, Trigger on — Create, Update, Delete, Filter — `_type in ["review", "settings", "partner", "testimonial"]`, HTTP method — POST.
6. **Эгани таклиф қилиш:** sanity.io/manage → лойиҳа → **Members → Invite** → эганинг email'и, роли Administrator ёки Editor.

## Ишлаб чиқиш

```bash
cd studio
npm install
npm run dev        # http://localhost:3333
```

Схемалар (майдонлар): `schemas/`. Сайт томони: `site/src/lib/cms.ts` (GROQ сўровлари), `site/src/lib/reviews.ts`, `site/src/config.ts`.
Майдон номини ўзгартирсангиз, `site/src/lib/cms.ts` ва `site/src/lib/reviews.ts` даги сўровларни ҳам янгиланг.
